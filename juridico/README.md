# Jurídico / burocrático — Onmode

Esta pasta **não é parte do app**. É só um lugar pra guardar documentos
societários, contratuais e burocráticos da Onmode junto do projeto, sem
misturar com o código-fonte (`src/`). Nada aqui é importado ou lido pela
aplicação em produção.

**Quem tem acesso**: hoje, só quem tem acesso a este repositório no GitHub.
Se o Arthur precisa ver/editar esses arquivos e ainda não é colaborador do
repo, adicione ele em *Settings → Collaborators* — ou considere manter os
documentos mais sensíveis (dados pessoais, valores, assinaturas) num lugar
separado (Google Drive, por exemplo) e usar esta pasta só como referência/
histórico de versões.
